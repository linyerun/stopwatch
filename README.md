# 念佛计时

一个 macOS App，记录每天念佛的时长与佛号声数。纯本地、不联网、无账号。
数据存放在 SQLite（系统自带 libsqlite3），界面分「念佛」与「记录」两页。

## 启动

三种方式，任选其一：

```bash
./build.sh                 # 构建 + 自测，完成后自动打开 App
open build/念佛计时.app     # 已经构建过时
./build.sh install         # 装进 /Applications，之后可从 Launchpad / 聚焦搜索打开
```

双击 `启动念佛计时.command` 也可以在 Finder 里直接启动（装了用装的，没装就现构建）。

要求 macOS 13 及以上，当前只编译 arm64（Apple 芯片）。构建只需 Command Line Tools
的 Swift 工具链，不需要 Xcode 工程。

## 用法

- **念佛页**（启动即显示）：阿弥陀佛接引像完整装裱为背景，底部悬浮控制坞（本座计时、
  念佛圆钮、操作与统计）。**点圆钮＝念一声南无阿弥陀佛**，回车键同样计一声，
  计数按本座累计、不归零。没开始本座时直接点圆钮会自动开始计时并计第一声。
- **记录页**：今日 / 本周 / 本月 / 累计时长、连续天数、佛号总数，近 36 周热力图，
  按日展开可看每座起止时间与声数并单独删除；右键某日可删除当天全部。
- **导出图片**：点「导出图片」直接把统计渲染成一张 PNG 并弹窗展示，可另存到任意位置。
  图里含累计/佛号/连续、今日本周本月、近 36 周热力图与最近十座明细。
- **菜单栏**：常驻一条状态文字（空闲时是今日累计，计时中是本座时长与声数），点开面板可
  直接计时、计数、看最近几座。窗口关掉后 App 仍留在菜单栏，Dock 图标随之消失。
- 不足 10 秒且一声未计的本座视为误触，不写入记录；只要计了声，就一定保存。

## 数据

`~/Library/Application Support/Stopwatch/stopwatch.sqlite3`，两张表：`sessions`（每座一行）
与 `active_seat`（进行中的本座）。每次点击即时写入，WAL + synchronous=FULL。
计时中退出 App 不会丢座：重启后从墙上时间继续，已念的声数也一并恢复。
早先用 JSON 存的历史记录会在首次启动时自动导入 SQLite，然后删除旧文件。

背景佛像由本仓库 `Assets/amitabha.png` 提供（AI 绘制，已裁掉生成水印），随 App 打包。

## 测试与调试

```bash
./build.sh                 # 63 项自测：SQL 读写与重开、JSON 迁移、计时累加、暂停不计入、
                           # 跨日汇总、连续天数、崩溃恢复、计数不归零、导出图片渲染
./build.sh shots           # 把四个界面离屏渲染到 build/shots/*.png（不需要屏幕录制权限）
```

| 环境变量 | 作用 |
| --- | --- |
| `NIANFO_DATA_DIR` | 换用其他数据目录，避免碰真实记录 |
| `NIANFO_DEMO=1` | 无记录时填入示例数据 |
| `NO_RUN=1` | 只构建，不自动启动 |

## 已知限制

- 本座时长按墙上时间计算：计时中若让 Mac 睡眠，醒来后会把睡眠时间一并计入，
  建议睡前先「结束本座」。
- 未做开机自启与全局快捷键（不聚焦窗口时无法用快捷键计数），需要时再加。
