# 念佛计时

一个 macOS 菜单栏 App，记录每天念佛的时长。纯本地、不联网、无账号。

## 构建

```bash
./build.sh
```

只需要 Command Line Tools 的 Swift 工具链（不需要 Xcode 工程）。产物是
`build/念佛计时.app`，脚本会顺带编译并运行自测（41 项断言，覆盖计时累加、
暂停不计入、跨日汇总、连续天数、崩溃恢复、导出格式）。

```bash
open build/念佛计时.app      # 菜单栏出现「佛 0:00:00」
```

要求 macOS 13 及以上，当前只编译 arm64（Apple 芯片）。

## 用法

- **菜单栏**：空闲时显示今日累计；计时中显示本座已念时长。
- **点开面板**：`开始念佛` → `暂停 / 继续` → `结束本座`。面板里还能直接进记录窗口或退出。
- **记录窗口**：今日 / 本周 / 本月 / 累计 / 连续天数 / 总座数，近 36 周热力图，
  按日展开可看每座的起止时间并单独删除；右键某日可删除当天全部。
- **导出**：CSV（Excel 可开）或 JSON。
- 不足 10 秒的本座视为误触，不写入记录。

## 数据

`~/Library/Application Support/Stopwatch/sessions.json`，每次操作即时落盘。
计时中退出 App 不会丢座：重启后从墙上时间继续，界面上会接着显示。

## 调试开关

| 环境变量 | 作用 |
| --- | --- |
| `NIANFO_DATA_DIR` | 换用其他数据目录，避免碰真实记录 |
| `NIANFO_DEMO=1` | 无记录时填入示例数据 |
| `NIANFO_OPEN_WINDOW=1` | 启动即打开记录窗口 |

`./build.sh shots` 会把界面离屏渲染到 `build/shots/*.png`（用真实视图代码绘制，
不需要屏幕录制权限），用于检查 UI。

## 已知限制

- 本座时长按墙上时间计算：计时中若让 Mac 睡眠，醒来后会把睡眠时间一并计入，
  建议睡前先「结束本座」。
- 未做开机自启与全局快捷键，需要时再加。
